The pilot is a practical check with one RE and two independent ARE/IOW computers. Automated development tests are preparation, not team sign-off. First use fictional observations in separate rehearsal profiles, then a limited set of genuine project observations.

Record each result, operator/date, device/browser, expected versus actual result, private evidence reference and any issue.
